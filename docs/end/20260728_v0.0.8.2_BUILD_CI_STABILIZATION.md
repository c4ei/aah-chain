# IEUM Chain v0.0.8.2

## 작업 목적

`v0.8.1` 기능 확장보다 먼저 컴파일 재발 방지와 자동 품질 검사를 구축한다.
실제 4노드 장기 시험 전 최소 조건은 모든 커밋이 컴파일되고 기존 합의·동기화
회귀 테스트를 통과하는 것이다.

## 처리 내용

- `ConsensusRuntime::certificates_from`의 누적 바이트 변수 타입을 `usize`로 고정했다.
- 패키지 버전을 `0.8.2`로 변경했다.
- GitHub Actions Rust CI를 추가했다.
- 다음 검사를 `main` push, pull request, 수동 실행에서 자동 수행한다.
  - `cargo fmt --all --check`
  - `cargo clippy --all-targets --all-features --locked -- -D warnings`
  - `cargo test --all-targets --all-features --locked`
  - `cargo build --release --locked`
- 동시 실행에서는 같은 브랜치의 오래된 검사를 취소한다.
- GitHub workflow 권한은 저장소 읽기로 제한한다.
- ROADMAP의 `0.7.1`·`0.8.1` 완료 범위와 실제 남은 제한을 현행화했다.

## 자동으로 확인되는 핵심 회귀 범위

- 4개 검증자 중 3개 precommit으로만 블록 확정
- 확정 전 원장 미반영
- 확정 인증서 없는 블록 동기화 거부
- 새 노드의 확정 인증서 기반 연속 동기화
- timeout 시 미확정 블록 미저장
- WAL 재시작 복구와 로컬 이중서명 차단
- 악성 피어 점수와 차단
- canonical state, mempool, keystore, 업그레이드 규칙

## 주의

현재 통합 테스트는 한 프로세스 안에서 4개 합의 실행기를 구동한다. CI 통과는
실제 서로 다른 서버 4대의 UDP/QUIC 지연, 패킷 유실, 프로세스 강제 종료와
재접속 시험을 대신하지 않는다.
