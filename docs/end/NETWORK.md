# P2P 네트워크 설계

## 전송과 검색

- 전송: QUIC v1(UDP), TLS 1.3 기반 암호화
- LAN 검색: mDNS
- 인터넷 검색: Kademlia DHT
- 초기 진입: 신뢰할 수 있는 bootstrap node 2~3개
- 전파: Gossipsub mesh를 이용한 다중 피어 전달

노드가 자신의 주변 IP 목록을 무작위로 브로드캐스트하지 않습니다.
libp2p의 서명된 PeerId와 발견 프로토콜을 사용해 IP 수집·위조 위험을 줄입니다.

## 기본 방어값

| 항목 | 기본값 | 목적 |
|---|---:|---|
| 단일 메시지 | 512 KiB | 메모리 고갈 방지 |
| idle timeout | 30초 | 죽은 연결 정리 |
| 명령 채널 | 128개 | 무제한 queue 방지 |
| 이벤트 채널 | 256개 | 소비자 지연의 영향 제한 |
| 임시 차단 | 10분 | 반복 악성 메시지 억제 |
| 차단 점수 | 100 | 작은 네트워크 오류와 공격 구분 |

운영 단계에서는 피어별 초당 메시지 수, 동시 연결 수, IP/subnet별 연결 수,
전체 inbound/outbound 연결 한도를 추가해야 합니다.

## 외부망 연결 점검

1. 서버 보안그룹과 UFW에 UDP 포트를 허용합니다.
2. 노드 로그의 PeerId를 확인합니다.
3. 사설 IP가 아니라 외부에서 접근 가능한 주소를 bootstrap 주소로 사용합니다.
4. bootstrap 한 곳에만 의존하지 말고 서로 다른 사업자의 노드를 둡니다.
5. 속도가 빠른 피어만 선택하지 말고 지역·ASN·subnet 다양성을 유지합니다.
