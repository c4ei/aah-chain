# IEUM Chain v0.0.11.2

## 목적

0.11.1 기능을 Rust 1.97의 `rustfmt`, `clippy -D warnings`, 테스트와 release build
검사 기준에 맞춘다.

## 반영

- 중첩 `if`, 불필요한 `as_bytes`, 큰 enum variant, iterator 마지막 원소 경고 수정
- `sync-quorum-peers` 명시적 범위 parser 유지
- 이후 버전의 각 코어 자료형에 회귀 테스트 추가

## 완료 조건

아래 CI가 모두 통과해야 0.11.2 완료로 판단한다.

```bash
cargo fmt --all --check
cargo clippy --all-targets --all-features --locked -- -D warnings
cargo test --all-targets --all-features --locked
cargo build --release --locked
bash tests/four_process_network.sh target/release/ieum-chain
```
