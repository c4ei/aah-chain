# IEUM Chain v0.0.14.1

## 저장 운영

- `Pruned`: 최근 높이와 주기적 체크포인트 보존
- `Archive`: 모든 높이 보존
- backup에 schema version, backend, chain id, height, state root manifest 기록
- restore 전에 chain id와 schema 검증

기존 embedded DB의 WAL/fsync 복구 경로는 유지한다. RocksDB/SQLite 네이티브
backend는 `Cargo.lock`을 실제 생성하고 release CI를 통과할 수 있는 Rust 환경에서
별도 migration 도구와 함께 적용한다. 단순히 이름만 RocksDB로 바꾸지 않는다.

## 관측

- `GET /metrics`: Prometheus text
- `GET /healthz`: 프로세스 health
- finalized height, peer, sync target, consensus round, signer failure,
  snapshot retry 지표

Grafana는 `/metrics`를 수집하는 Prometheus datasource를 사용한다.
