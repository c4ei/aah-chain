# IEUM Chain v0.0.6.5 자동 부트스트랩 및 연결 로그

## 요청 사항

- 버전을 `0.0.6.5`로 변경한다.
- 인자 없이 실행하면 일반 PC 클라이언트 모드로 시작한다.
- `server`만 지정하면 운영 기본값으로 실행한다.
  - P2P: UDP `7001`
  - RPC: `127.0.0.1:8989`
  - 노드 키: `data/server.node.key`
- 일반 PC에서 서버 PeerId나 다른 옵션을 직접 입력하지 않아도 자동 연결한다.
- 접속 및 종료 시 PeerId 외에 원격 IP, 주소, 연결 방향 등 운영 정보를 표시한다.
- 변경된 파일만 배포용 `tar.xz`로 제공한다.
- DB 변경이 없으면 SQL 파일을 생성하지 않는다.

## 처리 내용

### 실행 기본값

일반 PC는 아무 옵션 없이 실행한다.

```bash
cargo run --release
./target/release/ieum-chain
```

기본값은 P2P UDP `7001`, RPC `127.0.0.1:8989`,
노드 키 `data/client.node.key`이다.

운영 서버는 `server`만 지정한다.

```bash
cargo run --release -- server
./target/release/ieum-chain server
```

서버 기본값은 P2P UDP `7001`, RPC `127.0.0.1:8989`,
노드 키 `data/server.node.key`이다.

### 자동 부트스트랩

일반 PC는 시작할 때 `config/bootstrap.json`을 자동으로 읽는다. 운영 서버의 고정
PeerId가 포함된 주소가 기본 등록되어 있으므로 사용자가 `--peer`를 입력하지 않아도 된다.

```text
/dns4/node.ieum.aah.name/udp/7001/quic-v1/p2p/12D3KooWAVRZjnbP8nXp8vD6irYFAXdLJVyczEFWdKLFzKnKDATx
```

libp2p QUIC은 상대 신원을 검증하기 위해 PeerId가 필요하다. PeerId를 제거한 것이 아니라
영구 서버 키의 PeerId를 설정에 포함해 자동 사용한다. `data/server.node.key`를 교체하면
PeerId도 바뀌므로 해당 키를 백업하고, 교체할 때만 `config/bootstrap.json`을 갱신한다.

추가 부트스트랩 서버는 기존처럼 `--peer`로 지정할 수 있으며 설정 파일 주소와 합친 뒤
중복을 제거한다.

### 접속 및 종료 로그

연결 시 방향, PeerId, 원격 multiaddr, 원격 IP, 연결 ID와 현재 연결 수를 표시한다.
연결 종료 시에는 연결 유지 시간과 종료 원인도 함께 표시한다.

### 버전 및 DB

- `Cargo.toml`, `Cargo.lock`: `0.6.5`
- 데이터베이스 변경 없음
- `/sql` 파일 생성 없음
