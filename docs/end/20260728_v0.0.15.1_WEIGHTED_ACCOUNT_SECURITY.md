# IEUM Chain v0.0.15.1

Casper의 장점인 계정 다중키·가중치 임계값을 IEUM 계정 정책으로 구현했다.

- 키마다 허용 권한과 가중치 지정
- 일반 송금/고액 송금/검증자/복구 권한 분리
- 고액 송금은 더 높은 가중치 요구
- 정책 nonce가 다르면 과거 authorization 거부
- 복구 작업은 복구키 가중치와 실행 대기 높이를 모두 검증
- signer가 만든 실제 암호 서명 검증은 기존 `ValidatorSigner`/`ExternalSigner` 경계를 사용

키 분실·교체 시 기존 정책을 즉시 덮어쓰지 않고, 합의 상태에 `RecoveryRequest`를
등록한 뒤 대기 높이 이후 실행해야 한다.
