# IEUM Chain v0.0.6.9 원장 압축 및 서버 로그 회전

## 요청

- 활성 원장 약 99MB 제한이 적절한지 검토
- 마감된 블록 원장 압축 보관
- 서버 로그를 파일당 약 5MB로 회전
- 압축된 과거 서버 로그는 최대 5개만 보관

## 처리

- 버전을 `0.6.8`에서 `0.6.9`로 변경
- 활성 원장은 빠른 기록·복구를 위해 `active/blocks.jsonl` 비압축 유지
- 활성 원장이 99,000,000바이트를 넘거나 월이 바뀔 때 마감
- 마감된 원장을 zstd 레벨 3으로 압축하여 `backup/*.jsonl.zst`로 저장
- 기존 비압축 `backup/*.jsonl`과 신규 압축 파일을 모두 읽도록 호환성 유지
- 오래된 월별 백업의 연 단위 병합 결과도 `.jsonl.zst`로 저장
- `server` 명령에서만 `data/logs/ieum-chain.log` 파일 기록 활성화
- 현재 로그가 5MiB에 도달하면 `.1.zst`로 압축 회전
- 기존 압축 로그는 `.2.zst`~`.5.zst`로 이동하고 5개 초과분 삭제
- 터미널 표준출력은 기존처럼 유지
- 일반 PC 및 `client` 실행에는 파일 로그를 만들지 않음

## 저장 구조

```text
data/
  ledger/
    active/blocks.jsonl
    backup/202607M.jsonl.zst
    checkpoints/*.json
  logs/
    ieum-chain.log
    ieum-chain.log.1.zst
    ...
    ieum-chain.log.5.zst
```

## 참고

- 99,000,000바이트는 활성 원장 한 묶음의 상한이며 체인 전체 용량 제한이 아님
- 블록 해시와 검증은 압축 전 블록 데이터 기준이므로 압축 여부가 합의 결과를 바꾸지 않음
- DB 변경 없음
