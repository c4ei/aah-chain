# IEUM Chain v0.0.7.1 컴파일 수정

## 발생한 오류

- `src/lib.rs`에서 선언한 `logger` 모듈 파일 누락
- 동기화 응답 누적 바이트 변수의 정수 타입 추론 실패
- 확정 인증서의 블록을 원장에 적용한 뒤 인증서를 저장할 때 부분 이동 발생

## 수정 내용

- `src/logger.rs`를 변경분에 포함
- `bytes`를 `usize`로 명시
- 동기화 블록 적용 시 `certificate.block.clone()`을 사용해 인증서 소유권 유지

## 적용 파일

- `src/logger.rs`
- `src/consensus_runtime.rs`
- `docs/end/20260728_v0.0.7.1_COMPILE_FIX.md`

## 확인 명령

```bash
cargo fmt --check
cargo build --release
cargo test
```

이 수정은 체인 데이터 형식, 합의 규칙, DB 스키마를 변경하지 않습니다.
