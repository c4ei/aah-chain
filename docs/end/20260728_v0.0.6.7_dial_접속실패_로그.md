# IEUM Chain v0.0.6.7 dial 접속 실패 로그 보강

## 요청 사항

- 도메인 부트스트랩 주소를 사용할 때 실제 `dial()` 호출 여부를 로그로 확인
- 외부 서버 접속 실패 시 `OutgoingConnectionError`의 상세 원인 출력
- 변경된 파일만 압축하여 배포
- DB 변경이 없으면 SQL 파일을 생성하지 않음

## 처리 내용

- 부트스트랩 주소별 `swarm.dial()` 직전에 `[P2P 접속 시도]` 로그를 출력
- `dial()`이 즉시 거부되면 `[P2P 접속 시작 실패]`와 주소·오류를 출력
- 비동기 `SwarmEvent::OutgoingConnectionError`를 처리하여 대상 PeerId, 연결 ID,
  libp2p 전체 오류 내용을 출력
- 명령 채널을 통한 추가 피어 접속에도 동일한 접속 시도·시작 실패 로그 적용
- 버전을 `0.6.7`로 변경

## 확인 가능한 로그 예시

```text
[P2P 접속 시도] /dns4/node.ieum.aah.name/udp/7001/quic-v1/p2p/...
[P2P 접속 실패]
  PeerId: 12D3KooW...
  연결 ID: ConnectionId(1)
  오류: ...
```

## DB 및 SQL

- DB 변경 없음
- `/sql` 파일 생성 없음
