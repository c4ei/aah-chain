# IEUM Chain v0.0.6.8 DNS 기반 QUIC 외부 접속 수정

## 요청

- GitHub `c4ei/ieum-chain` 최종 소스를 기준으로 다음 버전을 만든다.
- `node.ieum.aah.name`을 공인 IP로 고정하지 않고 외부 PC가 QUIC 서버에 접속하게 한다.
- 변경된 파일만 배포 압축에 포함한다.

## 원인

`/dns4/node.ieum.aah.name/udp/7001/quic-v1/p2p/...` 주소가 QUIC transport에
그대로 전달되어 다음 오류와 함께 실제 UDP 접속 전에 종료됐다.

```text
Multiaddr is not supported: /dns4/node.ieum.aah.name/udp/7001/quic-v1/...
```

따라서 서버의 UDP 7001 포트에는 패킷이 도착하지 않았다.

## 처리

- 패키지 버전을 `0.6.7`에서 `0.6.8`로 올렸다.
- 설정 파일과 명령행에서는 `/dns4/node.ieum.aah.name/...` 주소를 그대로 사용한다.
- `swarm.dial()` 직전에 운영체제 DNS로 도메인의 IPv4 주소를 조회한다.
- 조회 결과를 `/ip4/공인IP/udp/7001/quic-v1/p2p/PeerId`로 바꿔 QUIC에 전달한다.
- DNS 조회 실패와 IPv4 결과 없음 오류를 구분해서 출력한다.
- DNS 변환 결과와 실제 dial 주소를 로그로 출력한다.
- 직접 지정한 `/ip4/...` 주소는 변경하지 않는다.
- IP를 소스에 고정하지 않으므로 DNS 주소가 바뀌면 다음 실행 또는 재접속 때 반영된다.

## 확인 로그

정상적인 외부 클라이언트에서는 다음 순서로 출력된다.

```text
[P2P DNS 변환] node.ieum.aah.name -> 122.35.243.20
[P2P 접속 시도] /dns4/node.ieum.aah.name/... -> /ip4/122.35.243.20/...
[P2P 연결]
```

서버 공유기는 외부 `UDP 7001`을 서버 사설 IP의 `UDP 7001`로 전달해야 한다.
`ping` 응답은 QUIC 접속의 필수 조건이 아니다.
