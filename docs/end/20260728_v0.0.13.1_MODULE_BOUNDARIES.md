# IEUM Chain v0.0.13.1

Cosmos의 코드를 포함하지 않고 다음 설계 원칙만 IEUM 방식으로 구현했다.

- 합의와 애플리케이션 상태 전이 분리
- `bank/`, `staking/`, `governance/`, `identity/`, `reward/` 상태 prefix
- 정렬된 key/value를 해시하는 결정론적 state root
- 모듈 이름으로 실행 경로를 선택하는 router
- 버전이 연속되지 않으면 중단하는 상태 migration

제한 WASM은 deterministic 실행량 계측과 sandbox가 준비된 뒤 별도 버전에서 연결한다.
