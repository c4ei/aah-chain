# v0.18.0 peer 보안 통신·IEUM 송금 연결

## 요청

- peer 간 화상채팅과 향후 원격 도움에 필요한 핵심 기능
- 사용자끼리 IEUM을 보내는 기능의 체인·UI 경계 정리
- 변경 파일만 배포

## 처리

- 체인 P2P에 암호화된 통화 연결 협상 envelope를 추가했습니다.
- 발신 peer 일치, 대상 peer, 만료 시간, 크기, hex 암호문, 중복 id를 검증합니다.
- 지갑이 사용할 로컬 RPC 송신·수신함을 추가했습니다.
- 통신 내용은 합의, 블록, 원장, 상태 DB에 넣지 않습니다.
- IEUM 송금 코어는 기존 표준 JSON-RPC를 그대로 사용하도록 정리했습니다.

## UI 경계

- `ieum-chain`: 잔액·nonce·서명 거래 검증·mempool·BFT 확정·암호화 신호 전달
- `ieum-wallet`: 주소록, 금액 입력, 수수료 확인, 전송 승인, 카메라·마이크,
  통신용 E2EE 키, WebRTC, 안전번호 표시

## 제외

- 검증자 키를 통신 암호화 키로 사용하는 동작
- 영상·음성·채팅 평문의 블록 저장
- 무인 원격 접속, 파일 전송, 클립보드, 관리자 권한
- 보안 감사 전 원격 키보드·마우스 제어
