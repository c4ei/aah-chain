# 제네시스 AAH 발행량과 이전

## 예제 제네시스에서 생성되는 수량

`config/genesis.example.json`의 `initial_balances`는 다음 한 건입니다.

```json
["0x0000000000000000000000000000000000000001", 1000000000000000000]
```

AAH는 geth 호환 RPC와 지갑 표시를 위해 소수점 18자리를 사용합니다.

- `1 AAH = 1,000,000,000,000,000,000` 최소 단위
- 예제 제네시스 총 발행량: **1 AAH**
- 최초 보유 주소: `0x0000000000000000000000000000000000000001`

총량은 `initial_balances`의 모든 두 번째 값을 더한 뒤 `10^18`로 나눕니다. 제네시스
파일을 바꾸면 제네시스 해시도 달라져 별개의 체인이 됩니다.

## 중요한 주의사항

예제 주소 `0x...0001`의 개인키는 프로젝트에 포함되어 있지 않습니다. 개인키가 없는
주소에 배분한 코인은 옮길 수 없습니다. 운영 전에 반드시 본인이 개인키 또는 니모닉을
보유한 Ethereum 형식 주소로 `initial_balances`를 교체해야 합니다.

제네시스를 시작한 뒤 주소만 수정하면 기존 체인의 코인을 이전하는 것이 아니라 새로운
체인을 만드는 것입니다.

## 권장 이전 절차

1. 오프라인 장치에서 Ethereum 호환 계정과 니모닉을 만듭니다.
2. 공개 주소만 `initial_balances`에 넣고 개인키/니모닉은 제네시스 파일이나 서버에
   기록하지 않습니다.
3. 4개 노드가 완전히 같은 제네시스 파일과 해시로 시작하는지 확인합니다.
4. 대상 계좌 주소, nonce, 체인 ID `21004`, 금액과 수수료로 EIP-155 legacy
   type-0 거래를 오프라인 서명합니다.
5. 서명된 hex를 RPC로 제출합니다.

```bash
curl -s http://127.0.0.1:8545 \
  -H 'content-type: application/json' \
  --data '{"jsonrpc":"2.0","id":1,"method":"eth_sendRawTransaction","params":["0x서명된_raw_transaction"]}'
```

잔액 확인:

```bash
curl -s http://127.0.0.1:8545 \
  -H 'content-type: application/json' \
  --data '{"jsonrpc":"2.0","id":1,"method":"eth_getBalance","params":["0x대상주소","latest"]}'
```

현재 구현은 EIP-155 legacy 단순 송금만 지원합니다. EIP-1559 거래와 컨트랙트 data는
거부합니다. 운영망에서는 개발용 체인 ID `21004`을 그대로 쓰지 말고 공개 체인과
겹치지 않는 운영 ID를 결정한 뒤 제네시스에 고정해야 합니다.
