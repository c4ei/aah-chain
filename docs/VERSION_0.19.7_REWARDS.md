# IEUM Chain v0.19.7 최초 참여 보상

## 요청

- 최초 검증자 4명이 완성되면 각 10 IEUM을 한 번만 지급
- 서명으로 확인된 서로 다른 노드가 최초 100개 이상 모이면 등록된 각 노드에
  1 IEUM을 한 번만 지급
- 각 노드의 보상 잔액을 다른 지갑으로 전송하는 명령 제공

## 처리

- 각 노드는 최초 실행 때 `data/reward.key`를 생성하고 재시작 후에도 같은 보상 주소를
  사용합니다.
- 보상 주소와 PeerId를 Ed25519로 서명해 P2P에 등록합니다.
- 두 보상은 BFT 확정 블록에 포함되고 실행 ID가 원장에 저장되므로 재시작,
  메시지 재수신, 동기화 뒤에도 중복 지급되지 않습니다.
- 지급 재원은 재단 계정이며 신규 발행으로 총공급량을 늘리지 않습니다.

## 명령

```bash
./ieum-chain reward address

./ieum-chain reward send \
  --to 0x받는지갑주소 \
  --amount 1 \
  --fee 0.000001
```

노드가 실행 중이고 기본 로컬 RPC `127.0.0.1:8989`에 연결할 수 있어야 합니다.
다른 RPC 포트라면 `--rpc-port`를 지정합니다.
