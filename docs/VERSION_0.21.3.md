# IEUM Chain v0.21.3 자동 역할 실행

## 요청 사항

- 일반 사용자는 설치 후 별도 옵션 없이 쉽게 실행한다.
- 외부 UDP 역접속이 가능한 노드는 공개 네트워크 지원 역할을 수행한다.
- 고급 사용자는 `auto`, `client`, `public`, `validator` 역할을 쉽게 선택한다.
- 공개 접속 가능 여부와 검증자 자격을 분리한다.
- 앞서 요청한 제네시스 테스트 주소의 `100 IEUM`과 4노드 PeerId 수정도 포함한다.

## 처리 내용

- 버전을 `0.21.2`에서 `0.21.3`으로 올렸다.
- 기본 `ieum-chain` 실행은 `--mode auto`와 동일하다.
- 자동 모드는 기존 `config/validator.key`의 공개키가
  `config/validators.json`의 승인 목록에 있을 때만 검증자로 실행한다.
- 검증자 자격이 없으면 일반 노드로 안전하게 실행하며, 기존 AutoNAT 역접속 판정이
  외부 직접 접근 가능 여부를 확인한다.
- 고급 사용자는 다음 명령을 사용할 수 있다.

```bash
./ieum-chain --mode auto
./ieum-chain --mode client
./ieum-chain --mode public
./ieum-chain --mode validator
```

- `server`, `client` 기존 명령은 운영 호환성을 위해 그대로 유지한다.
- `public`은 검증자가 아니며 외부 연결 지원을 시도하는 일반 노드다. 방화벽이나 NAT로
  역접속이 실패하면 일반 클라이언트처럼 계속 동작한다.
- `validator`는 검증자 키와 승인 목록을 준비하고 합의에 참여한다.
- 자동 판정은 공인 IP 보유 여부만 사용하지 않는다. 네트워크 시작 후 AutoNAT의 실제
  역접속 결과를 기준으로 공개 도달 가능성을 기록한다.

## 포함된 이전 변경

- `0x475e2f4e40Dbd34370e4fce61ddFF5Ff1F2eA817`에 제네시스
  `100 IEUM`을 배정한다.
- 전체 초기 배정량은 `80,100 IEUM`이다.
- 단일 서버 4노드 구성은 실제 `data/server.node.key`에서 PeerId를 계산하며, 키가
  없으면 임시 키를 만들지 않고 구성 전에 중단한다.

## 제네시스 적용 주의

이미 저장된 원장에는 바이너리 교체만으로 제네시스 잔액이 추가되지 않는다. 블록 높이가
`0x0`이고 실제 거래가 전혀 없는 신규 시험망에서만 네 노드의 원장을 각각 백업한 뒤
새 바이너리로 초기화한다. 검증자 키, 노드 키, `validators.json`은 삭제하지 않는다.
