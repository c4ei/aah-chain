# IEUM Chain v0.19.9

## 요청

- v0.19.9 사용자 매뉴얼 작성
- 무인 노드의 자동 업데이트와 합의 운영 방법 정리
- 실제 운영 전 빠진 기능과 위험 확인
- 가능한 운영 문제 수정
- AAH와 IEUM 교환 애플리케이션 구조 검토

## 처리

- `docs/USER_MANUAL_0.19.9.md`에 설치부터 장애 대응까지 통합했습니다.
- 반복 로그가 `\r`로 다른 비동기 로그와 합쳐지던 문제를 수정했습니다.
- 배포 노드 패키지에 `USER_MANUAL.md`를 포함합니다.
- 자동 업데이트는 서명 manifest와 SHA-256을 검증하는 비대화형 방식으로
  운영하고, 합의 변경은 BFT와 사전 지정 활성 높이로 분리했습니다.
- DEX UI, 양 체인 bridge, relayer, 체인별 잠금 모듈의 책임을 구분했습니다.

## 아직 활성화하지 않은 항목

- v0.19.8의 정책 코어를 실제 P2P 피어 관리에 연결
- 중계 영수증 전파·합의·이벤트 풀 자동 지급
- AAH ↔ IEUM bridge와 유동성 풀
- 검증자 거버넌스 제안·서명 UI

이 항목들은 합의·자산 안전에 직접 영향을 주므로 단위 코드만으로 켜지 않고
다노드 공격 시뮬레이션과 운영 키 절차를 먼저 확정합니다.
